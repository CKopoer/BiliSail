# Bili Lite

Flutter 原生哔哩哔哩客户端，当前版本 **0.1.0 Windows 预览版**。界面参考相邻 `biliuwp-lite` 和本机哔哩哔哩 UWP 的轻量白底、粉色强调、封面网格及播放详情分栏；Dart 实现独立编写，按用户要求选取的 UWP 图标来源与许可边界见 [第三方说明](THIRD_PARTY_NOTICES.md)。

## 已实现

- 游客推荐、热门、分区投稿、搜索与分页、视频详情、分 P；排行榜已接入，实测请求遇到服务端风控时显示错误和重试。
- 搜索提供综合、视频、番剧、影视、直播、专栏、用户七类，服务端分类计数、对应排序、时长/用户类型筛选和自动分页；综合页展示匹配 UP 主及投稿预览，影视/直播/用户使用内置入口，专栏在浏览器阅读。游客实测与边界见 [搜索分类与排序](docs/validation/search-categories.md)。
- 推荐、视频动态和搜索复用 16:9 视频卡片及自适应大卡网格；推荐显示接口提供的推荐理由，搜索保留 UP 图标与关键词高亮，视频动态去掉投稿标签。验证见 [共享视频卡片](docs/validation/shared-video-cards.md)。
- UWP 风格顶部多标签工作区、横向频道、紧凑视频网格；首页固定，搜索/视频/历史/设置独立打开，支持关闭、切换和页面状态保留。
- 首页提供动态/视频动态、稍后再看、收藏夹、番剧/国创/放映厅和直播的只读列表及子导航；私有列表需登录，影视和直播卡片进入应用内播放页。
- 我的收藏分为默认收藏夹、我创建的收藏夹、我的收藏与订阅、我的追番、我的追剧；收藏夹与个人主页夹内视频复用公共视频卡，订阅合集使用独立资源接口。Windows 已有会话的五类读取已验证，见 [收藏子标签与视频卡片](docs/validation/favorites-tabs.md)。
- 视频、影视、直播三类播放页共用一个原生播放器；影视支持分章节选集、简介和评论，直播支持房间/主播资料、开播状态、HLS/FLV、清晰度、实时聊天和画面弹幕。验证与未测项见 [影视与直播内置播放](docs/validation/content-playback.md)。
- 视频／影视隐藏控件时可显示底部细进度条，默认开启，应用／播放器设置均可关闭。直播播放器和右侧聊天／SC 下方提供同步草稿的文字及表情包发送栏；真实账号发送尚未在线验收，见 [验证记录](docs/validation/collapsed-progress-live-send.md)。
- 直播侧栏不显示简介，通过头像/主播名打开主页，右上显示平台报告的观看人数；历史与实时聊天支持行内/大表情，弹幕和 SC 用户名可按有效 UID 打开主页，见 [验证记录](docs/validation/live-chat-profiles.md)。
- 番剧、国创和放映厅的影视播放页参考官方桌面“哔哩哔哩”，使用简介／评论双标签，简介内嵌限高选集及系列作品；支持分组、列表／网格、正序／倒序和当前集定位。直播侧栏提供聊天／SC 双标签，聊天金额气泡可展开完整 SC，与 SC 列表共享快照及实时消息合并的状态；卡片按官方截图调整。当前结果见 [影视与直播弹幕修复](docs/validation/pgc-live-danmaku.md)。
- 首页频道及子标签统一提供右下角刷新/回顶部按钮，移除列表底部刷新；可分页列表在接近底部、首屏不足或窗口变大时自动补页，隐藏列表不自动翻页。设置中的“缓存图片”默认开启，跨频道共享封面缓存。实现和验证见 [首页刷新、自动分页与图片缓存](docs/validation/feed-scroll-image-cache.md)。
- 播放页参考官方桌面客户端，只保留简介／评论两个子标签；简介显示 UP 粉丝、累计获赞与关注入口，合集和分 P 整合在有界滚动卡片内，相关推荐直接展示，三部分用淡横线分隔。稍后再看和重新加载收进三点菜单。验证见 [简介侧栏](docs/validation/video-sidebar.md)。
- 评论展示头像、等级、认证/会员和粉丝勋章（按服务端字段），支持内联 B 站表情、图片预览、最热／最新排序及楼中楼；输入支持选择表情并插入光标处。评论和直播弹幕的表情选择统一使用居中弹窗，按系列子标签切换，见 [表情选择验证](docs/validation/emoticon-picker-tabs.md)。账户写入仅在用户明确点击后执行。
- 个人与 UP 主主页：账号弹窗、视频作者、评论和动态作者可打开独立用户标签；支持资料、投稿排序/搜索、动态、收藏夹、关注/粉丝及分页。服务端限制和平台实测边界见 [用户主页验证](docs/validation/user-profile.md)。
- 头像菜单显示等级/经验、会员/硬币和关注/粉丝/动态统计，提供个人中心、消息、稍后再看、收藏、历史、直播关注及登出入口。消息页支持私信、回复、@、点赞、系统通知，包含私信分页、文本发送和显式标为已读。Windows 已有会话的只读接口已验证；真实写操作及其他平台边界见 [账号菜单与消息验证](docs/validation/account-messages.md)。
- 主页投稿采用 UWP 横向卡片，显示封面时长、观看/弹幕数和日期；首页与空间动态共用限宽卡片，支持行内表情、多图、视频和转发引用，统计保持只读。验证见 [主页卡片与富动态](docs/validation/profile-dynamic-style.md)。
- H.264 / AAC DASH 分轨播放、暂停、seek、可用清晰度、倍速、音量、全屏。
- 视频/影视可选择 H.264、HEVC、AV1 编码偏好；视频、影视、直播可选择自动或软件解码，生效规则和平台实测边界见 [视频编解码设置](docs/validation/video-codec-settings.md)。
- 播放控件单行排列，弹幕输入框随宽度收缩；空间不足时切换紧凑控件，窄于 700 的窗口默认显示全高小窗布局，仍可展开视频信息。验证见 [播放控件与小窗布局](docs/validation/responsive-player.md)。
- 普通滚动／顶部／底部弹幕，分段预取、暂停／缓冲冻结和 seek 重定位。
- 字幕索引与 JSON cue 显示（在线样本无可用字幕，正文仅经过 fixture 验证）。
- Web 扫码登录流程、系统安全存储、会话恢复和退出隔离；完整的真实扫码登录仍待用户验证。
- 按账号隔离的本地历史与续播；外观、播放、弹幕、字幕与空降助手设置持久化，宽窄布局和键盘操作。
- UWP 视频动态横卡与头像、官方风格直播两级分区和封面网格。
- 视频点赞/取消赞、投币、收藏夹选择、稍后再看、复制分享链接与弹幕发送；写请求仅由用户点击触发，不自动重试。
- 空降助手默认关闭，启用后向独立第三方查询当前视频片段，支持提示/自动跳过，不携带账号、不自动上报。

各频道按自己的端点请求，失败显示错误和重试。收藏、订阅合集、追番和追剧已用本机已有会话只读验证；动态、稍后再看和直播关注列表的完整在线分页仍未验收。下载、UGC 云历史、后台音频和 PiP 仍未实现。影视和直播已验证 Windows 游客原生播放；影视发送栏、直播 WebSocket/画面弹幕、SC 新卡片与分区协议见 [影视与直播弹幕修复](docs/validation/pgc-live-danmaku.md)。该预览版不代表设计文档的完整 M2 或三端 M0 验收完成。首版记录见 [M0 验证](docs/validation/m0-results.md)，界面背景见 [界面与多标签验证](docs/validation/uwp-workspace.md)，播放器前序结果见 [播放器与标签保留](docs/validation/player-workspace.md)，本轮布局、配置和互动验证见 [界面控件与设置](docs/validation/ui-controls.md)。新增账号写接口已通过 fake/fixture 检查，未用真实账号执行投币、收藏或发送验收。

双标签播放页、楼中楼与评论互动的前序检查见 [播放页与评论交互](docs/validation/video-comments.md)，本轮快捷键、悬浮控制栏、富评论及图标检查见 [快捷键与富评论](docs/validation/shortcuts-rich-comments.md)。

已知限制：部分公网视频准备时间较长；Windows 辅助功能读取控件时曾触发 Flutter 原生崩溃，现已增加焦点与语义防护，但尚不能确认彻底消除。详见验收记录。

## 在 Windows 上运行

固定工具链为 Flutter **3.47.6** / Dart **3.13.5**，另需 Visual Studio 2022 的桌面 C++ 工作负载。依赖使用精确直接版本和提交的 `pubspec.lock`。

```powershell
flutter pub get
flutter run -d windows
```

生成可运行目录：

```powershell
flutter build windows --release
.\build\windows\x64\runner\Release\bili_lite.exe
```

分发／移动时必须保留整个 `Release` 目录，不能只复制 EXE。播放器原生库在构建时按插件固定来源下载，首次构建需要访问 GitHub。应用没有自动遥测，也不会自动点赞、投币或发送内容。

单击视频画面只切换底部悬浮控制栏；播放／暂停使用按钮或空格，双击画面切换全屏。快捷键默认沿用 UWP：左右键跳转 3 秒、长按右键临时 3 倍速，O/P 前进 90 秒，F/F11/Enter 全屏，Esc 退出全屏，W/F12 收起／展开视频信息，D/F9 切换弹幕，F6 切换字幕。设置页可编辑键位、逐项启停、恢复默认及调整步长、长按延迟和临时倍速。输入文本和模态弹窗期间不触发播放快捷键；截图、小窗、下载等未实现能力不绑定空操作。

有章节的视频在进度条显示自适应分段与标题，悬停／拖动显示时间、章节名和缩略图；右侧章节菜单可直接跳转。缩略图按需加载，移动指针不改变播放位置；无章节或图片时保留普通时间轴。实现与 Windows 指定视频实测见 [章节预览验证](docs/validation/playback-timeline.md)。

`Ctrl+T` 新建浏览标签，`Ctrl+W` 关闭当前标签，`Ctrl+Tab` / `Ctrl+Shift+Tab` 切换标签。最多打开 16 个标签，固定首页不可关闭；标签只在当前运行内保存。切到首页、搜索或用户页等普通标签时，原视频继续播放，隐藏页面移除画面和快捷键响应。返回同一视频沿用原播放源和当前进度；切到另一视频时单一播放器切源，保留各标签的精确进度、播放/暂停意图、倍速、音量、清晰度和字幕选择。关闭当前播放标签停止播放；关闭其他标签不影响它，不会同时播放多路音频。应用内切标签与移动系统后台不同，移动后台仍暂停。Windows 顶部空白处可拖动窗口，双击可切换最大化。

F1／分号减速，F2／单引号加速，按 `0.5、0.75、1.0、1.25、1.5、2.0、3.0x` 相邻档位调整；`Ctrl+1` 切换 1／2 倍速。菜单、设置和快捷键使用同一档位集合。用户页顶部对齐身份资料和统计，投稿排序与搜索在宽屏左右分布、窄屏分行。验证见 [用户页、倍速与标签播放](docs/validation/profile-playback-rates.md)。

设置页顶部按外观、缓存、快捷键、播放、弹幕、字幕、空降助手、关于分类。“缓存图片”可实时开关，采用有容量与有效期上限的本地图片缓存。快捷键中可配置关闭当前标签页，并通过输入或录制绑定鼠标后退/前进侧键及组合键。界面默认内置 HarmonyOS Sans，可在外观切换为系统默认字体；选择随设置保存。设置背景见 [设置分类、侧键与字体](docs/validation/settings-tabs-fonts.md)，图片缓存见 [本轮验证](docs/validation/feed-scroll-image-cache.md)。

## 检查与调试

```powershell
# 根应用与三个独立包：格式、分析、离线单元／widget 测试
.\tool\check.ps1

# Windows 原生受控媒体 + 系统安全存储测试
.\tool\test-windows-media.ps1

# 显式增加一次游客公开 API / 媒体 CDN 烟测，不使用账号
.\tool\test-windows-media.ps1 -Online

# 纯 Dart API 只读烟测
cd packages\bili_api
dart run tool\live_smoke.dart
```

正常测试使用 fake transport/repository/player 和人工生成的媒体，不需要真实账号。二维码 key、Cookie、签名媒体 URL 不写入日志或测试素材。测试媒体由已安装的 FFmpeg 生成；**应用不要求用户安装 FFmpeg**，原生解码来自 `media_kit` 的固定二进制。

播放诊断默认保存在应用数据目录的 `logs` 子目录；Windows 为 `%APPDATA%\dev.bililite\bili_lite\logs\playback-*.log`。记录 UTC 时间、源代次、播放位置/阶段、原生错误分类和可识别的 HTTP 状态，不保存原始错误文本、媒体 URL、请求头或账户信息，不自动上传。单文件最多 256 KiB、每次运行至多两份，创建/轮转时最多保留六份；写入队列最多 64 条，超量计数丢弃。旧版本未启用此日志，无法补录既往异常。误判原因与验证见 [播放错误排查](docs/validation/native-playback-errors.md)。

Android 工程的最低 API 为 24，macOS 工程最低版本为 12.0。这两个平台已创建入口、网络权限与依赖配置；本机 Windows 的成功不能证明两端运行正常。Windows、Android 和 macOS 的实际构建状态分别记录在验收文档。

## 工程结构

- `lib/app`：组合根、路由、主题和响应式导航。
- `lib/features`：按领域／数据／应用／界面划分实际功能。
- `lib/core`：SQLite、安全存储、请求取消与平台窗口能力。
- `packages/bili_api`：纯 Dart 协议、WBI、Cookie、QR、字幕与弹幕解码。
- `packages/bili_player`：PlayerEngine、media_kit 适配和 VideoSurface。
- `packages/bili_danmaku`：无网络的有界弹幕调度与 Canvas 绘制。

设计入口是 [文档索引](docs/README.md)，开发约定见 [AGENTS.md](AGENTS.md)。依赖与原生资产来源见 [第三方说明](THIRD_PARTY_NOTICES.md)。
