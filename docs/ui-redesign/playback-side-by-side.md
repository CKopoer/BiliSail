# 播放页左右布局 · 信息在下方

2026-11-22 设计提案。适用于普通播放窗口中的视频、番剧、国创、放映厅和直播间。

## 窗口布局

在已有左右布局中保留 380 逻辑像素宽的右栏，左栏改为上下两块。画面从左栏顶部开始，按原比例完整显示。标题和作者等内容紧接画面下缘，沿用页面主题和信息区的底色。播放控件、弹幕和字幕继续对齐画面，侧栏收起按钮对齐播放区右边缘的中线。

按参考截图取整，播放窗约为 1020 × 718，扣除标题栏后内容区约高 674。左栏宽 640，16:9 画面占 640 × 360。信息放到下方后可用高度约 314，右栏可以从第一行推荐、选集或聊天开始。原画面和新画面同大。

| 页面 | 画面下方 | 右栏 |
| --- | --- | --- |
| 视频 | 标题与展开入口、播放量／弹幕数／发布时间、UP 主与关注、原互动操作。展开后显示完整标题、简介与标签。 | 默认标签为「相关推荐」。有分 P 或合集时改称「选集与推荐」，先列分 P／合集再列推荐。评论标签、更多菜单和从稍后再看等入口带入的播放队列沿用原位置。 |
| 番剧、国创、放映厅 | 作品名与追番／追剧、当前集名、更新说明、已有统计与评分、可展开的剧情简介。访问限制随当前内容显示。 | 默认标签为「选集」，保留剧集分组、排序、列表／网格与相关系列。评论跟随当前集。单片有正片或预告时按实际片源分组展示。 |
| 直播 | 房间标题与开播状态、主播头像与名称、分区、房间号、在看／看过及人气。 | 「聊天」「SC」和刷新从顶部开始，底部固定弹幕输入栏。聊天流与 SC 详情继续使用原有滚动和跟随逻辑。 |

两栏独立滚动。展开长简介只滚动画面下的信息区，正在播放的画面、右栏标签、评论定位及聊天输入草稿均保留。视频操作保持原顺序，空间紧张时可横向滚动。收起整个信息区时两块信息一起收起，播放器使用整个内容区，再次展开时恢复当前标签和简介状态。全屏、听视频、小窗以及低于分栏阈值的上下布局继续按各自的呈现规则处理。

## 设置与自动选择

在「设置 → 外观」的「播放页左右布局阈值」之后增加「左右布局样式」。三类页面和独立播放窗口共用这个偏好。建议默认选择「自动」，旧设置缺少该项时也采用自动，用户已保存的分栏宽度继续生效。

| 选项 | 表现 |
| --- | --- |
| 自动 | 画面上下的空余高度能容纳本页折叠状态的信息时，使用「信息在下方」。 |
| 信息在右侧 | 使用当前样式，左栏为播放器，简介和其他内容都在右栏。 |
| 信息在下方 | 固定把内容信息放入左下。高度不足时，信息区最多占内容高度的 40%，区内可滚动，播放器在剩余空间内等比显示。 |

先按已有「播放页左右布局阈值」确定是否分栏，默认阈值为 1000 逻辑像素。进入分栏且显示信息时，再按以下规则决定自动样式。

1. 取当前播放页扣除标题栏、安全区后的内容高度 H，和扣除右栏后的左栏宽度 W。用当前视频有效显示宽高比 R 计算上下留白总高度 `max(0, H − W / R)`。始终用完整左栏计算，避免插入下方信息后又把它移回右侧。
2. 用左栏实际宽度、字体缩放和本页实际字段求出收起长简介时的信息高度。视频计入作者与操作行，影视计入当前集与简介摘要，直播计入房间资料。用户主动展开的长文由下方信息区滚动承载。
3. 建议留白达到「折叠信息高度 + 24 逻辑像素」时进入新样式。进入后，留白低于折叠信息高度才退回原样式。两条界线之间维持当前样式，拖动窗口时更稳定。
4. 首次打开且尚无可靠画幅时，自动模式先用右侧样式。新视频或直播流得到实际显示尺寸后重新判断。竖屏视频的左右留白不计入可用高度。布局只关注窗口尺寸、显示画幅、内容与文字缩放变化，切换呈现时复用同一播放会话和画面。
