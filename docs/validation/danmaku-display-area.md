# 弹幕显示区域与数量限制

## 原因与修复

点播和直播控制器都曾将轨道数量固定限制为 24。显示区域设置已正确保存并传递，但在大画面、小字号／小行距下，可用区域本可容纳超过 24 行，布局仍提前截止。滚动和顶部弹幕因此集中在上部；继续调大显示区域可能没有可见变化。底部弹幕从显示区域底边向上分配，也受同一轨道上限影响。

[点播控制器](../../packages/bili_danmaku/lib/src/danmaku_controller.dart) 与 [直播控制器](../../packages/bili_danmaku/lib/src/live_danmaku_controller.dart) 现按 `floor((视口高度 - 底部避让 - 有效顶部距离) × 区域比例 / 轨道高度)` 计算容量，轨道高度仍为当前文字测量高度加行距。轨道索引最多分配 `maxVisible` 行，默认 120，继续保持有界；同屏条数、逐帧接纳预算、时钟、追尾检测和缓存预算沿用原有规则。视口变化使用相同计算，只裁掉失去空间的活动项，放大不重放此前丢弃的弹幕。

显示区域为允许使用的最大范围；滚动／顶部弹幕优先使用上方空闲轨道，数量不足时不会强制均匀铺满。100% 仍保留顶部距离和字幕／控件底部避让。Android 的缺省区域为 50%，其他平台为 75%，以 [平台默认值](../../lib/app/platform_defaults.dart) 为准；有效旧设置保留，本次不调整默认值或设置存储格式。

## 当前数量边界

| 环节 | 默认与规则 |
| --- | --- |
| 每秒最大数量 | 默认 20 条，设置范围 0–100；0 取消这一层限额，点播按媒体秒筛选，直播按接收时间窗口计数 |
| 同屏数量 | 安全上限 120 条；设置范围 0–120，0 使用安全上限，非零值增加更低的限制 |
| 防重叠轨道 | 由实际区域、字号、行距及前后弹幕位置决定；无可用轨道时丢弃新弹幕，因此实际数量可低于同屏设置 |
| 待调度窗口／队列 | 最多 500 条；点播裁剪至当前时间附近，直播队列满时丢弃最旧等待项，超过允许等待年龄的消息不再显示 |
| 每帧文字准备 | 最多 32 条；其余到期项后续帧继续处理，不代表同屏最多 32 条 |
| 在线点播分段解码 | 普通弹幕每段最多保留 6000 条，超量有界抽样；不是整部视频的总量上限，见 [密集番剧记录](pgc-dense-danmaku.md) |

[共享设置控件](../../lib/shared/ui/danmaku_settings_controls.dart) 将同屏选项改为“同屏数量（0 为自动）”，并说明安全上限、轨道限制和显示区域语义；全局与播放器入口共用。

## 发送样式与成功回显

只读对照相邻 PiliPlus 提交 `936072449e82e3d90c28c728c0087bf5136fa441` 的 [弹幕配置适配](../../../PiliPlus/lib/plugin/pl_player/utils/danmaku_options.dart)、[发送面板](../../../PiliPlus/lib/pages/video/send_danmaku/view.dart)、[视频控制器](../../../PiliPlus/lib/pages/video/controller.dart) 和 [发送协议](../../../PiliPlus/lib/http/danmaku.dart)。其应用代码为 GPLv3；仅参考区域比例、播放 owner 保存发送选项、发送成功后按所选模式和颜色回显的行为，独立实现，不复制应用源码或引入相邻仓库依赖。该快照锁定的弹幕库为 `bggRGjQaUbCoE/canvas_danmaku@275046d8647a6a26cba1d0dadb9e28688cb3dbf1`，与本应用固定的 Predidit 依赖分别处理，未运行参考工程的 pub get 或修改它。

本应用原有 UGC／PGC 请求会传递模式与 RGB 颜色；问题在于两处发送栏各自持有 `_mode/_color`，输入栏随普通／全屏视图替换后恢复默认，且成功后没有将所发弹幕加入当前画面。现在由同一个 `PlaybackSession` 的局部通知器保存选项，两处入口共用 [发送样式按钮](../../lib/shared/ui/danmaku_send_style_button.dart)，选中标记和按钮颜色同步更新。选项仅在当前播放会话内保留，不新增全局偏好或数据库迁移。

`/x/v2/dm/post` 成功响应中的可选 `dmid_str/dmid` 以字符串沿 API／Repository 返回。只有确认成功且账号／会话代次和播放源仍有效时，才把原文字、发送时确认的媒体位置、模式与颜色加入会话内有界回显缓存，最多 120 条；换源／停止清理。窗口刷新按 ID 与后到的远端数据去重，无 ID 的成功响应使用会话内临时身份，不改为失败或重试。未知结果、失败、取消和迟到的旧源响应不回显，也不自动重新发送。

回显仍遵循弹幕总开关、模式／颜色／关键词过滤、偏移、已确认播放时钟与安全容量；成功响应没有权重字段，因此自发回显不参与权重与每秒远端限额过滤。回显不代表服务端已公开展示或审核通过。本轮没有执行真实账号发送。
