# 音量提示、标点倍速与关闭标签焦点

日期：2026-10-06。沿用 Flutter 3.47.6 / Dart 3.13.5 与锁定依赖。

## 本轮行为

- 快捷键调整音量及静音/恢复后，复用应用提示组件显示 `音量 N%`。提示不获取焦点，隐藏播放控件和全屏仍可看到；连续按键更新同一条提示，离开播放页或切换源后丢弃过期反馈。
- 倍速原先只通过逻辑键识别分号/单引号，无法匹配输入法或布局产生的其他键值。归一化保留稳定逻辑键的语义，并为标点提供物理键回退；F1/F2、自定义绑定、修饰键和开关继续沿用现有配置。此处是代码路径排查，真实输入法是否向 Flutter 交付按键仍需实键验收。
- `Ctrl+W` 原先被输入框焦点保护直接拦截。关闭标签现为工作区命令：配置了 Ctrl 或 Meta 的关闭组合键可在输入框持有焦点时执行；模态弹窗打开时仍屏蔽底层标签操作，单标签模式沿用返回逻辑，固定首页不能关闭。普通字符和其他操作的鼠标侧键绑定继续遵守输入保护；后续将关闭标签的侧键绑定也纳入工作区命令，修正其依赖 Ctrl+W 恢复的焦点问题，见 [侧键关闭与输入焦点修正](settings-tabs-fonts.md#侧键关闭与输入焦点修正2026-10-06)。
- 视频与影视的简介/评论保留在 IndexedStack 中，原先隐藏评论输入框仍可能占有焦点。两类播放页分别排除未显示子页的焦点，保持评论草稿和滚动状态；只读可选文本及游客只读输入框不再被视作正在编辑。
