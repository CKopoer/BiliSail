# 弹幕速度与播放倍速

日期：2026-10-06。普通视频与影视共用点播弹幕控制器，本次调整其时间语义。

## 行为

- 分段加载、时间偏移和弹幕出现时间继续跟随视频播放位置。视频倍速越高，同一真实时间内会触发更多媒体时间范围的弹幕，仍受轨道、密度和容量限制。
- 滚动位移、固定弹幕停留和轨道追尾判断使用独立动画时间，不乘播放倍速；弹幕自身的速度配置继续控制滚动时长。调整播放倍速和轻微位置校正保留活动项进度。
- 暂停、缓冲、定位中及位置样本超过 700ms 未更新时冻结两个时钟；恢复后继续。真实 seek 清空活动项，按确认媒体位置和当前倍速换算历史年龄，回退允许再次播放弹幕。
- 刷新时间窗保留仍可见的历史项；媒体回看范围随当前倍速和活动项调整。当前窗口的已调度 ID 有界保存，刷新不会重放已过期／丢弃的项，事件内容修改和 seek 会重置对应去重。
- 保留单 Ticker／局部绘制、视口变化保留进度和全部容量上限。未更改直播的消息到达时间、API、原生播放器或持久化设置。
