# 弹幕样式与过滤配置

日期：2026-10-06。按用户提供的播放器配置截图增量实现，保留工作区其他修改；关键词只在本地保存，按后续明确要求不接入云端同步。

## 配置入口与行为

应用设置的“弹幕”和播放器的“弹幕配置”复用同一个编辑器，保存到同一份设置，打开另一入口或重开弹窗可见已保存值。控件内拖动实时显示数值，松开后保存；保存失败回退偏好并显示错误。配置改变只重建弹幕布局/时间窗，不重开媒体源。

| 配置 | 当前行为 |
| --- | --- |
| 隐藏滚动弹幕 | 沿用滚动模式开关，以隐藏语义显示；顶部/底部模式仍可独立控制 |
| 显示区域、字号缩放、速度、不透明度、顶部距离 | 保留原有配置与范围；速度为原有移动速度倍率，顶部距离为逻辑像素 |
| 同屏密度 | 新增 0–120 条，默认 0 表示不额外限制；与每秒进入数量独立，仍受渲染器 120 条安全上限和轨道避碰约束 |
| 每秒最大数量 | 沿用原有默认 20 条，范围改为 0–100；0 表示不限制每秒数量，待调度容量仍为 500 |
| 弹幕字体 | 系统默认（保持此前绘制默认）或已打包的 HarmonyOS Sans；与界面字体分别保存，没有扫描或新增系统字体依赖 |
| 弹幕偏移 | 保存毫秒，范围 -60 至 +60 秒；支持输入、±1 秒和重置。点播正值延后、负值提前，播放器确认时钟本身不变；直播只应用正值延后，负值即时显示 |
| 字体加粗 | 默认关闭，使用真实粗体文本布局；轨道按测量行高预留空间 |
| 弹幕样式 | 阴影（保持默认）、黑色描边、无效果；描边先画轮廓再画原色文字 |
| 合并重复弹幕 | 默认关闭；同一可见时间窗内，相同文本和模式只保留第一条，颜色/发送人差异不拆分；前一条消失后允许再次显示，倒退 seek 可重播 |
| 屏蔽等级 | 0–10，默认 0 不过滤；点播保留服务端 `weight` 大于等于所选等级的弹幕。协议未提供权重时视为 0；直播没有此字段，不套用该规则 |
| 屏蔽彩色弹幕 | 默认关闭；按 RGB 过滤非白色文本，适用于点播和直播 |
| 关键词屏蔽 | 保留本地字面匹配、添加/删除、去重以及最多 200 项/每项 100 字的限制 |

点播按偏移后的弹幕位置预取前/当前/后一段；滑动窗口每 15 秒刷新，涵盖弹幕时间前 16 秒至后 60 秒，支持原有 0.5 倍移动速度的 16 秒滚动生命周期。seek、设置变化或 source generation 切换沿用旧请求隔离。字号变化更新活动项的尺寸，字体/效果变化释放旧缓存；点播和直播共享有界文本布局/绘制工具，各自保留独立调度时钟。直播延后队列仍有容量上限，隐藏或切房间清空积压。

## 持久化、来源与边界

既有 `preferences.v1` JSON 快照版本从 8 升为 9，添加字体、样式、加粗、合并、颜色过滤、权重阈值、偏移毫秒和同屏密度。缺失新字段时补上述默认值，未知枚举/非法范围归一化；原有偏好不丢失。没有 SQLite 表结构变化，不改变数据库 schemaVersion 或清空数据。

交互参考用户截图，另只读查看相邻 `biliuwp-lite` 已登记快照的 [弹幕设置](../../../biliuwp-lite/src/BiliLite.UWP/Controls/Settings/VideoDanmakuSettingsControl.xaml.cs)、[设置 ViewModel](../../../biliuwp-lite/src/BiliLite.UWP/ViewModels/Settings/VideoDanmakuSettingsControlViewModel.cs) 和 [NS 适配器](../../../biliuwp-lite/src/BiliLite.UWP/Services/NsDanmakuController.cs)。权重字段依据 `bili-kernel` 已登记快照的 [dm v1.proto](../../../bili-kernel/src/BiliKernel.Grpc/bilibili/community/service/dm/v1.proto) 中 `DanmakuElem.weight = 9`，扩展现有有界手写解码器，没有复制 C#/XAML 源码、schema 或资源；许可边界沿用 [参考文档](../references.md)。本轮不增加 API 端点，也未用真实账号验证权重分布。
