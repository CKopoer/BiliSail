# 播放页信息区滑动切换

## 范围与复用

普通视频与影视播放页的简介／评论、直播播放页的聊天（弹幕）／SC 支持触摸和触控笔横向分页。沿用首页、用户主页和设置页的 `RetainedTabView`、`PagingTabStrip` 与 `TabPagingMotion`；`PlaybackInfoTabs` 只组合播放信息区的标签栏、菜单／刷新入口与分页内容。

- 页面随手指移动，松手后吸附，短滑回弹；点击标签使用同一套过渡时长，并遵守系统减少动画设置。
- 标签指示条和文字颜色跟随分页进度；业务选择在滑动吸附完成后更新，逐帧进度不进入 Provider 或播放会话。
- 已访问的子页保持挂载，保留列表滚动位置、折叠状态与评论内部状态。隐藏子页隔离焦点、指针和活动标记；收起信息区或隐藏工作区取消尚未提交的拖动。
- 播放器位于分页区之外，切换信息子页不重新创建播放器。直播消息连接由房间页面持有，不随聊天／SC 子页切换重新连接；聊天自动跟随和手动暂停跟随沿用原逻辑。
- 视频和影视评论继续按需首次构建。直播聊天和 SC 已由同一个房间控制器加载，使用 `RetainedTabView.preloadPages` 显示首次拖动中的现成内容；该选项默认关闭，不改变首页、用户主页和设置页的加载策略。
- 鼠标拖动内容不切换子页，纵向列表滚动、桌面滚轮、滚动条及直播 SC 金额气泡的横向浏览继续使用原有滚动行为。

## 双标签换视频恢复到评论加载占位（2026-10-25）

- 双标签的播放槽保留同一个 `VideoScreen` State。此前 `didUpdateWidget` 只更新分 P，视频 ID 改变后仍继承旧的评论 Tab 选择；现在新视频回到简介并收起旧简介正文，同一视频换 P、宽窄布局切换和信息区显隐仍保留当前子标签。
- `TabBarView` 内部的 PageController 默认会从 PageStorage 恢复横向页码。详情加载期间分页卸载再挂载时，即便业务选择已经是简介，也可能恢复到旧评论页；标签指示条随后跟随该页码，但未访问的评论页仍显示静态加载占位，评论组件没有构建。这一状态无需评论网络请求失败即可稳定复现。
- `RetainedTabView` 为分页位置使用实例内的 PageStorageBucket，由业务选择确定初始页；子页列表继续使用原工作区 bucket，并携带外层页面的 PageStorageKey 命名空间，保留纵向滚动恢复和不同页面间的隔离。视频信息分页另按视频 ID 区分生命周期，避免已访问页和未完成的翻页跨视频延续；播放器仍位于分页外。
- 已读取用户正在运行的本地 Windows Release 的结构化日志 `playback-1792914614168872-29684.log`。该日志仅含播放器的 `openStarted`、`openReady`、`nativeLog`，没有评论请求、页面选择或 Flutter Widget 异常记录，不能单凭它判断评论网络是否卡住。上述原因来自旧实现的失败回归和源码路径核对。

## 进入播放页的默认子标签（2026-10-27）

- 设置 → 播放新增“进入播放页默认显示评论区”开关，默认关闭（显示简介）；开启后新视频和新影视作品优先显示评论区。仍可手动点击或滑动切换简介／评论，同一视频换 P、同一作品换集、宽窄布局切换、信息区收起再展开和保留页面重新可见时保留当前选择。
- 默认偏好只在页面首次进入或复用播放槽打开新视频／作品时应用；修改设置不强制切走当前页面已选的子标签。影视没有评论入口时显示简介，直播不使用此设置。
