# 直播卡片人气缩略

日期：2026-10-07。

[直播卡片](../../lib/features/feed/presentation/home_feed_cards.dart) 原来直接显示接口的 `popularityText`；推荐／分区列表中的 `online` 数字由协议包保留为十进制文本，因此会出现完整长数字。

现在直播卡片复用 [公共视频卡片计数格式器](../../lib/shared/ui/video_card.dart)：十进制文本从 1000 起使用千、从 10000 起使用万、从 100000000 起使用亿，保留一位小数，例如 `1234 → 1.2千`、`12345 → 1.2万`、`123456789 → 1.2亿`。接口已提供的 `8万`／`2.34亿` 等缩略文本原样保留；0 显示 0，缺失或空白不显示人气。千缩略通过可选参数仅在直播卡片启用，普通视频卡片的现有规则保持。

此次只改变展示，沿用现有接口、模型、响应式网格与房间点击行为。

## 验证

- [直播卡片回归](../../test/features/feed/live_room_card_test.dart) 覆盖纯数字单位边界、服务端缩略／未知文本、0／空白、语义文本、140 逻辑像素宽及两倍字体下的点击。
- `flutter test --no-pub` 对直播卡片、共享视频卡片、首页响应式网格与首页布局的定向 34 项测试通过，日志为 `build/live-card-count-tests.log`。
- 修改文件的格式检查与定向静态分析通过。

本轮没有修改原生播放；未进行 Windows／Android／macOS 实机界面验证或新的在线接口验证。
