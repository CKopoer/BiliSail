# 评论与直播表情选择

日期：2026-10-05。在现有未提交工程上增量修改。

## 交互

视频评论表情入口由输入框下方展开改为居中弹窗；直播播放器及侧栏的表情入口使用同一弹窗样式。弹窗顶部按服务端表情包系列显示子标签，点击切换，系列较多时可横向滚动。内容区只构建当前系列，表情列表独立滚动。

评论选中表情后关闭弹窗，替换草稿选中文字或插入光标处，恢复输入焦点；取消保留草稿。直播普通表情追加草稿，图片表情沿用预览，未解锁表情保留锁定提示及禁用选择。选择表情不发送评论或弹幕，发布／发送仍由用户另行点击。

弹窗保留现有加载、空结果和失败重试状态，使用原页面 ProviderContainer；评论返回选择结果时检查页面身份、账号 scope 和 session epoch。共享组件只负责展示，不访问 Repository 或协议模型；两处仍使用各自控制器和领域表情类型。
