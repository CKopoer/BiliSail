# 私信聊天设置操作修复

日期：2026-11-05。修复私信聊天标题右侧齿轮弹窗中置顶、免打扰、移除和手动已读的页面状态归属问题。

## 原因与实现

- 工作区在根 Navigator 下为每个页面覆盖 `messagesControllerProvider`；聊天设置使用根 Navigator 展示，弹窗直接读取该 Provider 时取得另一份消息控制器。真实会话不属于该控制器，管理操作被当前会话校验拒绝；即使测试仓储共用同一对象使写入成功，更新的也不是原页面状态。手动已读的可用状态同样误读了另一份聊天列表。
- 弹窗现在显式接收原页面控制器及消息状态，通过原页面的 `listenManual` 订阅同步开关、忙碌状态和错误提示。弹窗结束时关闭订阅并释放快照；源页面销毁时订阅由页面释放，弹窗不再访问已销毁的 ProviderContainer。
- 各项操作重新解析原页面当前选中的会话，检查 Repository 身份、账号 scope、session epoch 和会话身份。拉黑／移除确认后与举报提交前再次核对，页面关闭、账号过期或会话变化后不执行旧操作。
- 置顶／免打扰成功后更新原页面和弹窗；请求进行中禁用冲突操作，失败保留原值并展示已有错误分类。刷新、已读沿用原页面回调。没有新增协议、依赖、数据库迁移或私信持久化。
