# 应用内专栏阅读

搜索结果的“专栏”是 B 站专栏检索类型，旧版专栏使用 `cv` ID。B 站将部分专栏迁移到使用 `opus` ID 的图文作品页面。普通动态也可能采用图文作品格式，动态详情接口仍以动态身份读取摘要和互动。专栏阅读使用对应的正文接口，保留两个 ID 的独立语义。

- 搜索响应带有效的作品地址时，直接使用该地址的身份。只有旧专栏 ID 时，匿名探测官网阅读地址的重定向，识别同站 `/opus/{id}` 后读取新版正文。重定向缺失时，按旧版接口返回的 `opus.opus_id` 识别迁移作品。两个来源均未提供作品身份时读取旧版正文。新版响应明确回退到旧版 ID 时直接读取指定专栏。
- 搜索、历史、动态及消息使用工作区独立阅读页。`/article/:id`、`/opus/:id` 支持直接进入、跨篇跳转和按工作区历史返回。模块化图文、旧版 HTML 和笔记正文转换为可选择文本、标题、图片、链接、引用和代码等原生内容。正文图片复用共享缓存和查看器。标题栏保留浏览器原文入口，图片不附带账号凭据。
- HTML 由 Dart `html` 解析器读取，仅转换受支持的静态元素。忽略脚本、iframe 与第三方远程图片，关闭和账号变化取消旧请求。内容受限时显示服务端说明，读取失败可重试。

## 正文与评论

宽屏正文在左、评论在右，两栏可独立滚动。窄屏及放大字号后的单栏布局默认只显示正文，右侧常显阅读滚动条。点击评论进入独立的全宽评论窗口，返回后继续在原位置阅读。带楼层定位的消息或链接直接打开评论窗口，返回时先退出楼中楼。

- 宽屏标题栏的「调节专栏与评论宽度」打开比例滑块。两栏按实际可用宽度实时调整，各占 30% 至 70%。松手时将比例写入全局布局偏好，其他专栏和重启后的应用继续使用。旧设置缺少比例、值无效或恢复默认时，沿用自动分栏。评论栏空间不足时，排序按钮和评论数、刷新按钮分两行显示。
- 专栏页使用工作区表面色、返回键和整页可用高度。正文沿用动态的卡片、作者栏和文字样式，宽屏阅读区居中。
- 解析器把已校验的公共 CDN HTTP 地址升级为 HTTPS，读取新版 `line.pic` 图片分隔线，HTML 懒加载地址无效时回退到 `src`。不含参数的已知 CDN 缩略图后缀可还原为原图路径，签名参数保留。预览继续通过有大小上限的共享图片缓存加载。
- 旧专栏按实际读取的 CV 号和评论类型 12 加载，包括新版接口回退到旧专栏的情况。新版图文按 `item.basic.comment_id_str` 和 `comment_type` 加载评论，响应中的 `module_stat.comment` 提供评论数和禁评状态。作品 ID 与评论业务 ID 分别保留。
- 阅读页复用动态详情的共享评论区，支持最热／最新、分页、楼中楼和作者主页等交互。登录和发送沿用现有评论流程。已关闭评论或缺少有效评论身份时，页面显示相应提示，正文仍可阅读。受限正文沿用服务端提示。
- 消息及正文链接中的合法根评论、楼中楼 ID 或 `#reply…` 可直接定位到专栏回复；按资源 ID 查询动态的通知保留原有动态详情路径。

正文按当前栏宽和文字样式测量段落高度，图片按宽高比预留位置。列表缓存各块的高度，可见范围内再创建交互内容和加载图片。旧实现按当前可见段落估算全文高度，鼠标拖到长段落时滑块会偏离指针。用 200 段长短混排的测试文章复现时，首次拖动前后最大滚动距离从约 6,237 变为 11,981 逻辑像素。修复后拖动期间全文高度稳定，操作栏的滑出动画也保持阅读视口高度和滑轨长度固定。

## 文集与底部操作

新版图文的 `module_collection` 和旧专栏响应中的文集身份在标题下生成文集入口。官网 `readlist/rl…` 链接和只有文集号的历史记录进入 `/article-list/:id`。带篇目 CV 号的文集历史打开上次阅读的正文。目录显示封面、作者、篇数、字数、阅读数及篇目摘要，支持正序／倒序和进入作者主页。打开篇目优先使用有效的 `dyn_id_str`，只有 CV 号时沿用迁移探测。返回目录会保留排序与滚动位置。

操作栏位于正文底部，初始可见，向文末阅读时收起，向文首回看时展开。显隐只跟随正文，宽屏右侧评论可使用整栏高度。窄屏点击评论按钮时才首次加载普通评论，宽屏点击会回到右栏首屏。转发和点赞复用动态控制器，收藏按实际读到的 CV／opus 身份提交，服务端确认后更新选中状态和数量。写入结果不明时，用户可从页头刷新并核对。页头还提供复制链接、浏览器打开，以及符合分享条件的专栏发送至消息。
