# 应用内专栏阅读

搜索结果的“专栏”是 B 站专栏检索类型，旧版专栏使用 `cv` ID。B 站将部分专栏迁移到使用 `opus` ID 的图文作品页面。普通动态也可能采用图文作品格式，动态详情接口仍以动态身份读取摘要和互动。专栏阅读使用对应的正文接口，保留两个 ID 的独立语义。

- 搜索响应带有效的作品地址时，直接使用该地址的身份。只有旧专栏 ID 时，匿名探测官网阅读地址的重定向，识别同站 `/opus/{id}` 后读取新版正文。无有效迁移目标时读取旧版正文。新版响应明确回退到旧版 ID 时直接读取指定专栏。
- 阅读页使用工作区标签和返回历史。模块化图文、旧版 HTML 和笔记正文转换为可选择文本、标题、图片、链接、引用和代码等原生内容。阅读位置沿用工作区页面存储，正文图片复用共享查看器。标题栏保留主动在浏览器打开原文的入口，图片不附带账号凭据。
- HTML 由 Dart `html` 解析器读取，仅转换受支持的静态元素。忽略脚本、iframe 与第三方远程图片，关闭和账号变化取消旧请求。内容受限时显示服务端说明，读取失败可重试。专栏相关互动、专栏历史上报和专栏收藏未纳入阅读流程。
