# 个人空间滚动收起与播放全部

日期：2026-10-30。

个人空间（包括自己的个人主页）在内容宽度小于 600 逻辑像素时，复用首页／我的的 `ScrollHeaderRegion` 与 `ScrollCollapsingHeader`：内容列表上滑收起资料，下滑恢复，投稿／动态／收藏夹／关注／粉丝导航保留。横向切页、程序滚动、隐藏工作区和不足以滚动的列表不触发收起。较长简介仍可在资料区内独立滚动；宽屏资料区继续固定。各标签、搜索草稿、列表实例与滚动位置保留，账号代次变化重置资料显隐。

投稿顶部增加“播放全部”。点击后从第一页读取该 UP 的公开投稿，采用点击时的排序，忽略空间中的搜索关键词；无需登录，不修改远端稍后再看。读取成功后以不透明队列 ID 进入现有视频播放页，展示“用户名的投稿”，复用稍后再看队列的展开／收起、选择、上一／下一视频和连续播放逻辑。投稿队列不展示“从稍后再看删除”，也不受稍后再看移除状态影响。连续播放仍服从现有播放设置，先播放当前视频剩余分 P，再进入下一投稿；手动选择保持播放／暂停意图。

队列由播放页持有分页控制器，独立于空间列表的 500 条浏览上限与空间页面生命周期。接近队尾、滚动到队尾或点击“加载更多投稿”时逐页读取，按 BVID 去重；单次读取有 30 秒期限。只读失败保留已有队列并提供重试，重试沿用失败页码；连续三页没有新增投稿时停止自动读取。关闭播放页或账号状态变化取消读取，并通过 scope／session epoch 隔离迟到响应。

沿用最多 16 个队列、每个队列最多 1000 条的内存约束。超过 1000 条时，只移除当前视频之前的已播放条目，继续读取后续投稿；因此这不是把前 1000 条当作该 UP 的全部视频。计数使用累计偏移，尚未读完时显示 `+`。已经移出窗口的早期条目不再提供队列回退；服务端增删投稿可能改变按页读取的顺序，属于现有公开投稿接口的边界。
