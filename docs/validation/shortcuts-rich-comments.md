# 快捷键、悬浮控制栏与富评论

日期：2026-10-05。本轮在现有未提交工程上增量修改；相邻参考仓库只读使用。

## 参考证据与实施范围

实际查看本机 **哔哩哔哩 UWP 4.8.18.0** 的快捷键设置及视频评论页；与相邻 `biliuwp-lite` 的 `Models/Functions/BaseShortcutFunction.cs`、`Controls/Settings/ShortcutKeySettingsControl.xaml` 交叉核对。默认左右跳转 3 秒，O/P 快进 90 秒，长按右键临时倍速，左键支持持续回退；空格、全屏、铺满窗口、音量、弹幕、字幕、倍速和前后分 P 对应既有播放器能力。UWP 设置另含尚未在本项目实现的截图、小窗、下载等行为，不能由快捷键列表推导为本项目已支持。

视频画面单击切换悬浮控制栏显隐，鼠标移动、快捷键和等待不再自动显示或隐藏控件，播放/暂停由按钮或快捷键触发。无障碍点击使用相同切换逻辑；播放错误仍显示错误提示及恢复控件。全屏和布局变化沿用单一 PlaybackSession 与 native surface。

评论沿用现有分页、楼中楼及单次发送流程，扩展服务端身份标识、内联表情、图片和输入框表情选择；源字段和协议测试与 UI 分层，图片请求不携带账号凭据。没有增加图片上传或真实账号自动发送。

图标按用户要求从参考仓库选取，应用平台图标同步替换。具体资源、哈希、生成方法与许可边界记录在 [资源来源](../../assets/README.md) 和 [第三方说明](../../THIRD_PARTY_NOTICES.md)。

## 配置和会话边界

快捷键为纯 Dart 类型化配置，随既有 SQLite `preferences.v1` 设置保存，JSON `schemaVersion` 从 2 升为 3；SQLite 表结构与数据库版本未变，读取旧快照保留原字段并补默认键位。支持操作开关、总开关、组合键、多个别名、冲突检查、恢复默认；前进/后退步长、长按触发延迟和临时倍速分别有界。

后续增量已增加设置专属分类、鼠标侧键和界面字体，当前设置快照版本为 4；见 [设置分类、侧键与字体](settings-tabs-fonts.md)。

| 行为 | 默认键位 |
| --- | --- |
| 播放/暂停 | Space |
| 切换/退出全屏 | F、F11、Enter / Esc |
| 收起/展开信息侧栏 | W、F12 |
| 前后跳转 | ←、→，默认 3 秒；→ 长按 400 毫秒后临时 3 倍速 |
| 大步快进 | O、P，90 秒 |
| 音量 | ↑、↓，每次 5；静音可自行绑定 |
| 弹幕/字幕 | D、F9 / F6 |
| 减速/加速 | F1、分号 / F2、单引号，每次 0.25 倍 |
| 切换 1/2 倍速 | Ctrl+1 |
| 上一/下一分 P | Z、N、逗号 / X、M、句号 |
| 新建/关闭标签 | Ctrl+T / Ctrl+W |
| 刷新 | Ctrl+R、F5 |

`Ctrl+Tab` / `Ctrl+Shift+Tab` 保留用于工作区标签循环。UWP 的持续快进/快退独立模式未移植；截图（F10）、小窗（T/F8）、下载（Ctrl+S）、重启（Alt+R）和开发模式（Ctrl+F12）无现有底层能力，在设置中明确列为暂未启用。

长按倍速由 PlaybackSession 保留原速度，释放恢复，工作区快照保存原速度。失焦、失活、换源和销毁取消长按计时；文本输入及模态弹窗阻止播放器快捷键，隐藏标签不响应。图片预览是模态窗口，评论文本可选择复制。

普通播放页进入、标签重新激活及退出全屏后，播放器在画面挂载后获取键盘焦点；正在输入或有模态弹窗时不抢占焦点。此前仅全屏主动获取焦点，普通页面可能将焦点留在工作区，导致播放快捷键收不到事件。仅有空格可用也可能是焦点按钮自身的激活行为，不能据此判定播放器的快捷键分发正常。原有测试先点击画面，掩盖了进入页面时的焦点缺失；现增加真实工作区路由下直接按键的回归。

仅在进入时获取焦点仍不足以覆盖后续的侧栏交互。播放快捷键现由当前活动播放页在焦点导航前处理：焦点停在推荐项、侧栏按钮或进度滑块时，音量、倍速等已配置键位仍可生效。上下方向键的重复事件连续调音量，不再落入列表导航；倍速切换等单次动作不会因重复事件再次切换。未绑定/禁用的键继续交给原控件，焦点控件的 Space/Enter 激活语义保留。输入框、模态弹窗、隐藏页继续屏蔽播放快捷键；长按倍速记录按下时的焦点，失焦/失活/换源后释放；页面销毁时移除按键处理器与焦点监听。

表情面板读取选定包时用网格懒构建，颜文字按文本处理；内联表情失效时显示原 token，图片失败时保留可读占位。缩略图、表情和大图预览分别限制解码尺寸；评论最多 9 张图片，内联表情最多 100 项，包最多 50 个、每包最多 200 项。
