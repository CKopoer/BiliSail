# 播放控件与小窗布局

日期：2026-10-05。在现有未提交工程上增量调整，未修改相邻参考仓库。

## 行为

- 常规底部工具栏保持单行，播放、弹幕输入、清晰度、倍速、音量和全屏按钮垂直居中；投屏、听视频、弹幕配置、字幕样式与播放配置在画面右上角。全屏保留与其他图标相同的 40 像素按钮区域，进入／退出全屏图标于 2026-10-27 微调为 18 逻辑像素，使视觉大小更协调，其余工具图标保持 20 逻辑像素。
- 弹幕输入框随剩余空间收缩，默认最小宽度 200、最大宽度 420（Flutter 逻辑像素）；最小宽度跟随文字缩放增长。布局根据时间标签、可用清晰度、字幕和文字缩放计算需要的空间，不再在固定 1050 宽度拆成三行。
- 非全屏且容纳不下完整工具栏时，小窗保留全部可用按钮，按播放／下一集／时间／全屏及其他工具分为两行。第二行保留弹幕开关、发送、清晰度、倍速、字幕、语音、音量和更多入口，按内容能力显示；极窄窗口或大字号下支持触摸横滑、桌面滚轮和可拖动滚动条。顶部保留返回／主页、人数、投屏、听视频及配置入口。普通宽布局与全屏沿用原有控件。
- 小窗点播保留可拖动的进度条及缓存、章节、悬停预览；控件收起后按“隐藏控件时显示底部进度条”设置显示底部细条。直播不显示点播进度条。
- 小窗将弹幕输入替换为“发送弹幕”按钮，点击打开当前窗口内的发送弹窗；窄屏底部对齐、宽屏居中，限制最大宽度并避让安全区及软键盘。视频／影视／直播复用原发送组件，保留样式或表情入口、登录和发送状态。关闭／重新打开、宽窄和全屏切换保留草稿，不自动发送；全屏紧凑工具栏继续通过发送入口展开／收起输入。
- 普通视频页与影视播放页默认展开简介／评论，宽度足够时左右分栏，窄窗口中将信息放到 16:9 播放器下方；调整窗口大小不自动收起信息。宽屏通过画面右侧按钮、普通／全屏通过 W/F12 可手动收起／展开，收起后播放器占满可用高度，宽窄切换保留用户选择。隐藏信息区继续挂载，保留子标签和滚动状态。
- 布局切换沿用同一 PlaybackSession 和 VideoSurface，不重开媒体源，不改变进度、暂停或倍速。这里的小窗是当前应用窗口内的响应式布局，不创建独立窗口，也不新增系统 PiP、置顶或后台播放能力。
