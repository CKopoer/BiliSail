# 直播聊天室连接提示

日期：2026-10-07。

直播播放页原先将“实时弹幕已连接”等连接阶段文案放在聊天列表外，连接正常后仍固定占用一行。现在提示作为 [LiveScreen](../../lib/features/live/presentation/live_screen.dart) 聊天列表的一项显示：阶段改变时放在已有消息之后，新聊天从它下方继续追加，随着列表跟随最新消息自然向上滚出。

提示位置以阶段变化前最后一条消息的去重键确定，连接成功与首条弹幕在同批到达时，提示仍位于新弹幕之前。历史快照补充 UID 等元数据不会改变其顺序；在看／看过人数或心跳人气更新不会将连接提示重新移到末尾。只保存当前阶段的一条提示，已有消息锚点被 500 条聊天窗口淘汰时一并移除；重新连接时显示当前的新阶段提示。没有聊天时将提示放在空态之后，窄窗口默认跟随到底部也能看到连接结果。

既有手动上滚暂停跟随、手动到底恢复跟随、侧栏及聊天／SC 切换、SC 阅读位置和重连入口沿用原行为。换房或控制器清空消息时重置提示锚点，不增加协议事件、领域聊天消息或持久化设置。

验证：`flutter test --no-pub test/features/live/live_screen_test.dart` 的 23 项组件测试通过；新增 4 项覆盖连接提示位置与自然滚出、手动回看、有界淘汰和重新连接、人数更新不重新插入、历史元数据补充、320px／双倍字号及换房。对应源码和测试的 `dart analyze`、格式检查、`git diff --check` 通过。

本项只调整 Flutter 聊天展示，未调整原生播放。真实直播窗口、Android／macOS 实机和长时间运行没有在本项单独实测；自动化覆盖不代表这些平台交互已验收。跟随行为的前序设计与验证见 [直播侧栏、表情弹幕与主页入口](live-chat-profiles.md#聊天列表自动跟随修正2026-10-06)。
