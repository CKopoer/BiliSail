## 功能与入口

| 功能 | 行为与专项记录 |
| --- | --- |
| 视频定时 | 宽屏右上角、窄屏更多菜单，与听视频复用同一弹窗和截止时间；支持 1–1440 分钟，切换模式不清除，到期暂停。[定时](listening-sleep-timer.md) |
| 播放模式 | 设置页及播放器设置中选择播完暂停／连续播放／列表循环／单集循环；默认暂停，兼容旧连续播放偏好，循环按实际列表顺序且不扩展到相关视频。[播放模式](continuous-playback.md) |
| 移动端状态栏 | Android／iOS 的共用播放页顶部安全区黑底、浅色图标，返回浏览或 UP 空间后恢复原背景。[状态栏](mobile-playback-status-bar-2026-11-06.md) |
| 动态直播跳转 | 首页和空间的直播动态、转发内直播卡片进入既有应用内直播页。[动态与评论](dynamic-live-comment-time-2026-11-06.md) |
| 评论时间 | 视频、动态和楼中楼共享“刚刚／n分钟前／n小时前／昨天／n天前”及较早日期格式。[动态与评论](dynamic-live-comment-time-2026-11-06.md) |
