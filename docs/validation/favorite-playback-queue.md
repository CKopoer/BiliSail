# 收藏夹播放全部与播放列表

日期：2026-10-30。

## 交互与实现

- 默认收藏夹、打开后的创建/订阅收藏夹与订阅合集，以及个人主页内打开的收藏夹显示“播放全部”。父级收藏夹列表、追番与追剧列表不显示该按钮。
- “播放全部”从列表首个有效视频开始；点击某个收藏视频则从该视频开始。播放器展示有序列表和收藏夹标题，复用稍后再看的展开/折叠、当前项定位、上一/下一项、分 P 优先和自然结束连续播放。收藏夹播放列表不显示稍后再看的删除按钮，也不受稍后再看删除记录影响。
- `FavoritePlaybackQueueController` 经现有 `HomeRepository` 独立分页读取，不受浏览列表已经加载的页数或 500 条浏览上限影响。使用已有 `/x/v3/fav/resource/list`、默认收藏夹识别及 `/x/space/fav/season/list` 管线，不新增协议、写请求或依赖。失效 BVID 跳过，同一视频按首次出现的位置去重，保留计数、作者、权限和字符串 aid。
- 沿用 `WatchLaterQueue` 与进程内 registry，增加收藏标题和截断标识；保留原类型名，以缩小已有入口的迁移范围。账号 scope 与 session epoch 必须一致，公开收藏夹支持游客。关闭列表取消准备请求；切换收藏夹或页面隐藏后，迟到结果不触发导航；新会话不能消费旧快照。
- 准备期间按钮禁用并显示加载状态，总时限 60 秒；分页失败不发布半份列表，重试从第一页重新读取。连续三页没有新资源或超过 100 页即停止并提示分页异常。
- 一次最多扫描前 1000 条收藏资源，播放器仍按视口懒创建卡片；大收藏夹明确提示本次范围，计数附加 `+`，不将截断内容称为完整收藏夹。此上限包含失效和重复资源。队列不落盘，不保存签名媒体 URL 或凭据。

## 参考来源与采用边界

只读核对本地 PiliPlus 提交 `936072449e82e3d90c28c728c0087bf5136fa441` 的 `lib/pages/fav_detail/view.dart`、`controller.dart` 与 `lib/pages/video/controller.dart`：参考“播放全部”选取首个有效视频、传递收藏夹身份/标题、播放页持有列表的职责。PiliPlus 按资源身份增量获取媒体列表；本项目采用已有 Web 收藏分页并生成有界内存快照，接入现有播放会话。独立编写 Dart/Flutter，没有复制 GPLv3 应用代码或资源、修改相邻仓库，也未采用其依赖或新增运行时依赖。许可边界见[参考文档](../references.md)。
