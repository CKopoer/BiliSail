# 收藏夹播放全部与播放列表

日期：2026-10-30。

## 交互与实现

- 默认收藏夹、打开后的创建/订阅收藏夹与订阅合集，以及个人主页内打开的收藏夹显示“播放全部”。父级收藏夹列表、追番与追剧列表不显示该按钮。
- “播放全部”从列表首个有效视频开始；点击某个收藏视频则从该视频开始。播放器展示有序列表和收藏夹标题，复用稍后再看的展开/折叠、当前项定位、上一/下一项、分 P 优先和自然结束连续播放。收藏夹播放列表不显示稍后再看的删除按钮，也不受稍后再看删除记录影响。
- `FavoritePlaybackQueueController` 仅准备初始一页：点击视频读取其浏览来源页，“播放全部”读取第一页；初始最多加入 99 个有效视频。使用已有 `/x/v3/fav/resource/list`、默认收藏夹识别及 `/x/space/fav/season/list` 管线，不新增端点、写请求或依赖。失效 BVID 跳过，同一视频按首次出现的位置去重，保留计数、作者、权限和字符串 aid。
- 沿用 `WatchLaterQueue` 与进程内 registry，增加收藏标题和截断标识；保留原类型名，以缩小已有入口的迁移范围。账号 scope 与 session epoch 必须一致，公开收藏夹支持游客。关闭列表取消准备请求；切换收藏夹或页面隐藏后，迟到结果不触发导航；新会话不能消费旧快照。
- 准备期间按钮禁用并显示加载状态，单次读取总时限 30 秒；准备失败不发布列表，分页失败保留已加载内容并重试原页。播放页使用共享 `PlaybackQueueController`，个人／UP 主空间与“我的”收藏仅在来源读取适配上不同，不再维护两套播放列表推进规则。
- 初始队列只有一页、最多 99 个视频；之后在播放列表上下滑动逐页加载，活动窗口最多 999 个。超限移出另一端的整页，可以反向读回；保留可见条目位置、当前播放来源页提示、上一／下一项和完播接续。双向连续三页无新内容时暂停自动读取并提示重试。队列不落盘，不保存签名媒体 URL 或凭据。
- 部分订阅 UGC 合集端点忽略 `ps`，一次返回整张合集：数据层将其转换为每页 99 条的本地分页快照，后续同一游标前后翻页无需重复下载整张合集。快照按账号 scope／session epoch 隔离，账号变化立即清除；最多保留 16 份 LRU 快照、每份最多 5000 条资源。浏览刷新不会重定向已有队列的快照；游标失效或不属于当前收藏夹时明确拒绝，不改读另一份数据。
- 稍后再看按用户后续要求保留原有完整列表快照、条目顺序、删除和同步行为，不接入本轮收藏分页流程；其现有容量规则不变。
