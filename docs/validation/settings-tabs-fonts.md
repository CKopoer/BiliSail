# 设置分类、鼠标侧键与界面字体

日期：2026-10-05。本轮在现有未提交工程上增量修改。

## 实施范围

设置页顶部使用“外观、快捷键、播放、弹幕、字幕、空降助手、关于”分类，替代首页的推荐、热门等频道；每个分类只显示对应控件。分类经 `/settings?section=<category>&tab=<workspace-id>` 路由更新同一个工作区标签，切换浏览/视频标签后返回仍保留原分类。缺省或未知分类回退到外观，各分类分别保留当前运行内的滚动位置。

快捷键设置优先展示标签页与页面操作，其中“关闭当前标签页”默认 `Ctrl+W`，可编辑、停用或解除绑定。所有已有快捷键操作支持 `MouseBack`（鼠标后退侧键）、`MouseForward`（鼠标前进侧键）及 Ctrl/Alt/Shift/Meta 组合；可以直接输入稳定键名，也可以在录制对话框的提示区按下侧键。侧键默认不绑定操作；普通左/右/中键和同时按下多个鼠标键不会被识别为侧键快捷键。侧键前进按下时单次跳转，键盘长按临时倍速逻辑保持原有语义。

侧键沿用总开关、单项开关、冲突检查以及文本输入/模态弹窗保护。播放页的侧栏和画面均可触发当前活动播放器操作，隐藏播放标签不响应；工作区关闭仍保护固定首页。同一次指针事件在嵌套监听和播放器全局路由之间只消费一次。全局指针监听随播放器视图销毁解除，没有额外播放器实例。

外观提供 HarmonyOS Sans 和系统默认两项界面字体，浅/深色主题实时应用选择。默认使用用户提供的简体中文 Regular/Medium/Bold 三个文件，原样打包，不依赖系统安装或桌面目录在运行时存在。字体、原始许可证与来源哈希见 [资源记录](../../assets/README.md#harmonyos-sans)。关于页不展示字体介绍，仍可进入完整许可证页。

2026-10-06 后续增加阿里巴巴普惠体 3.0 和 Windows/macOS 已安装字体搜索，界面/弹幕分别保存；上述两项为最初实现范围，当前行为与快照版本见 [字体选择验证](font-selection.md)。

## 持久化与兼容

字体选择写入既有 SQLite `preferences.v1` 设置快照，JSON `schemaVersion` 从 3 升为 4，新增 `font` 字段。SQLite 表结构及数据库 schemaVersion 仍为 1，无需删库或改表。旧快照缺少字体字段时补 HarmonyOS Sans，其他设置和快捷键覆盖值保留；未知字体值安全回退到 HarmonyOS Sans。鼠标侧键和组合键沿用现有快捷键绑定字段，可随设置保存/重载。

## 关闭标签快捷键修正

普通页面的搜索框经鼠标点击外部失焦后，焦点回到工作区外层的路由焦点域。原来的 `Focus.onKeyEvent` 只接收后代焦点向上冒泡的事件，此时 `Ctrl+W` / `Ctrl+T` 均无法到达工作区；视频页会主动取得播放器焦点，因此表面上只有播放页有效。新增回归在修改前确认搜索框已失焦，但 `Ctrl+W` 未关闭当前标签。

工作区现在统一注册键盘事件前置监听，仅分发既有的新建和关闭标签操作，销毁外壳时解除监听。输入框持有焦点或模态路由打开时继续屏蔽操作；总开关、单项开关、自定义键位、解除绑定、固定首页保护与鼠标侧键语义保持一致。只处理按下事件，长按重复事件不会连续关闭多个标签。

真实页面关闭回归还暴露了直播页销毁时同步调用 `setActive(false)` 引起的 Riverpod 构建期状态修改。页面现将仍存活控制器的停用安排到当前构建之后；若标签作用域已销毁，继续由控制器既有的 `ref.onDispose` 取消请求、计时器和消息订阅。

回归覆盖新建浏览、搜索、历史、设置、下载、用户主页、视频、影视和直播九类真实页面，另覆盖搜索框鼠标失焦、自定义/禁用/空绑定、输入框保护、获取或不获取焦点的弹窗、重复按键单次关闭及监听销毁。

本轮最终 `tool/check.ps1 -SkipPub` 通过：根应用 447 项、bili_api 129 项、bili_player 16 项、bili_danmaku 10 项，共 602 项；根应用和三个包的格式检查、静态分析均通过。专项工作区/直播回归 75 项通过，并验证页面卸载后仍被订阅的直播控制器取消消息读取、解除实时订阅、忽略迟到事件与停止定时重开。日志为 `artifacts/workspace-close-check.log` 和 `artifacts/workspace-close-targeted.log`。
