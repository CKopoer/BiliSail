# 设置分类、鼠标侧键与界面字体

日期：2026-10-05。本轮在现有未提交工程上增量修改。

## 实施范围

设置页顶部使用“外观、快捷键、播放、弹幕、字幕、空降助手、关于”分类，替代首页的推荐、热门等频道；每个分类只显示对应控件。分类经 `/settings?section=<category>&tab=<workspace-id>` 路由更新同一个工作区标签，切换浏览/视频标签后返回仍保留原分类。缺省或未知分类回退到外观，各分类分别保留当前运行内的滚动位置。

快捷键设置优先展示标签页与页面操作，其中“关闭当前标签页”默认 `Ctrl+W`，可编辑、停用或解除绑定。所有已有快捷键操作支持 `MouseBack`（鼠标后退侧键）、`MouseForward`（鼠标前进侧键）及 Ctrl/Alt/Shift/Meta 组合；可以直接输入稳定键名，也可以在录制对话框的提示区按下侧键。侧键默认不绑定操作；普通左/右/中键和同时按下多个鼠标键不会被识别为侧键快捷键。侧键前进按下时单次跳转，键盘长按临时倍速逻辑保持原有语义。

侧键沿用总开关、单项开关、冲突检查以及文本输入/模态弹窗保护。播放页的侧栏和画面均可触发当前活动播放器操作，隐藏播放标签不响应；工作区关闭仍保护固定首页。同一次指针事件在嵌套监听和播放器全局路由之间只消费一次。全局指针监听随播放器视图销毁解除，没有额外播放器实例。

外观提供 HarmonyOS Sans 和系统默认两项界面字体，浅/深色主题实时应用选择。默认使用用户提供的简体中文 Regular/Medium/Bold 三个文件，原样打包，不依赖系统安装或桌面目录在运行时存在。字体、原始许可证与来源哈希见 [资源记录](../../assets/README.md#harmonyos-sans)。关于页不展示字体介绍，仍可进入完整许可证页。

2026-10-06 后续增加阿里巴巴普惠体 3.0 和 Windows/macOS 已安装字体搜索，界面/弹幕分别保存；2026-10-07 按用户要求移除内置普惠体及其选项，保留系统字体搜索。上述两项为最初实现范围，当前行为与快照版本见 [字体选择验证](font-selection.md)。

## 持久化与兼容

字体选择写入既有 SQLite `preferences.v1` 设置快照，JSON `schemaVersion` 从 3 升为 4，新增 `font` 字段。SQLite 表结构及数据库 schemaVersion 仍为 1，无需删库或改表。旧快照缺少字体字段时补 HarmonyOS Sans，其他设置和快捷键覆盖值保留；未知字体值安全回退到 HarmonyOS Sans。鼠标侧键和组合键沿用现有快捷键绑定字段，可随设置保存/重载。

## 关闭标签快捷键修正

普通页面的搜索框经鼠标点击外部失焦后，焦点回到工作区外层的路由焦点域。原来的 `Focus.onKeyEvent` 只接收后代焦点向上冒泡的事件，此时 `Ctrl+W` / `Ctrl+T` 均无法到达工作区；视频页会主动取得播放器焦点，因此表面上只有播放页有效。新增回归在修改前确认搜索框已失焦，但 `Ctrl+W` 未关闭当前标签。

工作区现在统一注册键盘事件前置监听，仅分发既有的新建和关闭标签操作，销毁外壳时解除监听。输入框持有焦点或模态路由打开时继续屏蔽操作；总开关、单项开关、自定义键位、解除绑定、固定首页保护与鼠标侧键语义保持一致。只处理按下事件，长按重复事件不会连续关闭多个标签。

2026-10-06 后续调整：带 Ctrl/Meta 的关闭标签命令在输入框中也可执行，模态路由继续保护；视频/影视隐藏评论子页排除焦点，只读文本不再按正在编辑处理。当前边界与本轮验证见 [音量提示与快捷键焦点](keyboard-feedback-focus.md)。上一段保留原阶段行为说明。

真实页面关闭回归还暴露了直播页销毁时同步调用 `setActive(false)` 引起的 Riverpod 构建期状态修改。页面现将仍存活控制器的停用安排到当前构建之后；若标签作用域已销毁，继续由控制器既有的 `ref.onDispose` 取消请求、计时器和消息订阅。

回归覆盖新建浏览、搜索、历史、设置、下载、用户主页、视频、影视和直播九类真实页面，另覆盖搜索框鼠标失焦、自定义/禁用/空绑定、输入框保护、获取或不获取焦点的弹窗、重复按键单次关闭及监听销毁。

## 侧键关闭与输入焦点修正（2026-10-06）

搜索、评论或弹幕输入框保留焦点时，原先的工作区输入保护会拦截未带 Ctrl/Meta 的鼠标侧键关闭命令。Ctrl+W 可以关闭当前标签并改变焦点，因此表现为“侧键失效后，先用 Ctrl+W 关闭一次才能恢复”。新增回归在修复前确认后退/前进侧键在单标签和多标签模式下均无法关闭有编辑焦点的页面。

绑定到“关闭当前标签页”的 MouseBack / MouseForward 及其修饰键组合现与 Ctrl/Meta 关闭命令一致，可在输入框持有焦点时执行；单标签模式继续按历史返回。普通字符和未带 Ctrl/Meta 的键盘绑定、新建标签、刷新及播放器操作继续遵守输入保护，模态弹窗仍阻止关闭底层标签。总开关、单项开关、固定首页保护和每次按压只执行一次的规则保持一致。

- 专项工作区、实际页面路由、鼠标事件消费与播放器回归共 102 项通过。新增用例覆盖页面输入框和顶部搜索框持有焦点时连续关闭、两种导航模式、后退/前进侧键、保留上一页草稿、长按跨重建只关闭一次、固定首页及其他命令的输入保护；既有用例增加侧键弹窗与停用保护。
- `tool/check.ps1 -SkipPub` 通过：根应用 788 项、bili_api 249 项、bili_player 16 项、bili_danmaku 32 项，共 1085 项；四部分的格式检查和静态分析均通过，日志为 `build/mouse-close-tab-check.log`。
- `flutter build windows --release --no-pub` 成功，入口为 `build/windows/x64/runner/Release/bilisail.exe`，需保留同目录 DLL 与 data 资源；构建日志为 `build/mouse-close-tab-windows-build.log`。
- 键盘和鼠标事件由 Flutter 测试框架注入；Windows 物理鼠标驱动与 Android/macOS 实机行为仍待验收。

## 设置分类触摸分页（2026-10-09）

当前八个分类“外观、缓存、快捷键、播放、弹幕、字幕、空降助手、关于”支持触摸／手写笔左右分页，跟手、吸附和短滑回弹，首尾不循环。顶部设置分类栏位于分页之外，并与内容共用连续动画进度。滑动落定后更新同一个工作区标签的 `/settings?section=<category>&tab=<workspace-id>`；外部路由选择、隐藏工作区和取消手势可以取代尚未完成的拖动。

设置内容复用原有控件与全局设置控制器，首次选中的分类才挂载；已访问分类保留独立滚动位置和控件状态，关闭工作区时释放。进入或切换分类不会自动保存设置，滑块的水平拖动继续调整原设置，桌面鼠标不触发分类分页，列表仍保留滚轮与滚动条。

新增 5 项设置页行为回归覆盖全部分类双向遍历／首尾边界、短滑／取消／鼠标拖动、滚动位置与正常保存、隐藏／外部选择以及桌面滚轮／滑块；另有真实路由回归确认分类更新与工作区页面复用。共享标签栏、完整自动检查与实机验收边界见 [子标签栏过渡验证](single-page-navigation.md)。
