# 视频与听视频定时关闭

日期：2026-11-06；初版听视频需求：[issue #56](https://github.com/CKopoer/BiliSail/issues/56)。

## 交互与生命周期

- 普通视频、影视与离线视频在宽屏播放器右上角提供白色定时图标，开启后用半透明底色标示，提示中显示剩余分秒；窄屏通过“更多播放选项”进入。听视频保留顶部入口、浅／深主题与剩余分秒显示，大字号使用带剩余时间提示的图标。普通／全屏共用同一个计时器；直播和全局设置不增加入口。
- 所有入口复用同一弹窗，提供 15／30／45／60／90 分钟与自定义 1–1440 分钟，默认选中 30 分钟。点击“开始计时”才生效，关闭弹窗保留当前状态；重新设置从当前时间起算，开启时可“取消定时”。
- 采用会话级截止时间，暂停、缓冲、隐藏页面、系统后台及连续播放的分 P／合集／相关视频／剧集切换均继续计时。计时不依赖媒体位置、倍速或 Flutter 帧，不写入偏好、数据库或导航检查点。
- 到期立即撤销播放意图并暂停当前会话，保留位置与当前视频／听视频模式。已排队的片尾回调、相关视频读取、加载中的下一项和模式切换不能重新自动播放；用户显式点击播放或系统播放命令可以继续。
- 视频与听视频往返保留原截止时间，到期后的暂停状态也保留。停止会话、账号清理、关闭播放页、切换为直播或退出应用时取消；重启应用不恢复。切换浏览页和系统退后台继续计时。
- `PlaybackSession` 持有唯一会话计时器；原生事件和播放同步检查截止时间，补偿后台事件循环延迟。界面仅局部每秒刷新剩余时间，界面卸载不取消会话计时。

## 平台边界

本功能没有新增系统闹钟或后台服务。平台若暂停应用进程，恢复后按截止时间处理；应用被系统结束时不会保留计时任务。Android／macOS／iOS／Linux 的设备、锁屏及长期后台验收本轮未执行。
