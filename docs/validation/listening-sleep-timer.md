# 视频与听视频定时关闭

日期：2026-11-08；初版听视频需求：[issue #56](https://github.com/CKopoer/BiliSail/issues/56)。

## 交互与生命周期

- 普通视频、影视与离线视频在宽屏播放器右上角提供白色定时图标，开启后用半透明底色标示，提示中显示剩余分秒；窄屏通过“更多播放选项”进入。听视频保留顶部入口、浅／深主题与剩余分秒显示，大字号使用带剩余时间提示的图标。普通／全屏共用同一个计时器；直播和全局设置不增加入口。
- 所有入口复用同一弹窗，提供 15／30／45／60／90 分钟与自定义 1–1440 分钟，默认选中 30 分钟。点击“开始计时”才生效，关闭弹窗保留当前状态；重新设置从当前时间起算，开启时可“取消定时”。
- 本次播放期间共用一个截止时间，暂停、缓冲、隐藏页面、系统后台及连续播放的分 P／合集／相关视频／剧集切换均继续计时；新建播放页直接继承剩余时间。计时不依赖媒体位置、倍速或 Flutter 帧，不写入偏好、数据库或导航检查点。
- 到期立即撤销全部保留播放会话的播放意图并暂停，保留各自位置与视频／听视频模式。已排队的片尾回调、相关视频读取、加载中的下一项和模式切换不能重新自动播放；用户显式点击播放或系统播放命令可以继续。
- 视频与听视频往返保留原截止时间，到期后的暂停状态也保留。关闭部分播放页、停止单个媒体源或打开直播均不取消共享定时；直播仍不提供设置入口。关闭最后一个播放页、账号清理或退出应用时取消；重启应用不恢复。切换浏览页和系统退后台继续计时。
- `PlaybackManager` 持有唯一计时器并注入正式 `PlaybackSession`，到期同步撤销所有会话意图。关闭最后一页时立即清除截止时间，不等待原生释放，也不让迟到的旧会话释放取消新定时。独立测试会话可自行持有计时器；原生事件和播放同步检查截止时间，补偿后台事件循环延迟。界面仅局部每秒刷新剩余时间，界面卸载不取消共享计时。

## 平台边界

本功能没有新增系统闹钟或后台服务。平台若暂停应用进程，恢复后按截止时间处理；应用被系统结束时不会保留计时任务。Android／macOS／iOS／Linux 的设备、锁屏及长期后台验收本轮未执行。
