# UWP 风格界面与多标签工作区

日期：2026-10-05。基于同一 Flutter 3.47.6 / Dart 3.13.5 Windows 主机，按用户截图、本机已安装 UWP 的推荐/热门页面及相邻只读源码实现。当前仓库尚无提交，不虚构 revision。

本文保留上一轮交付的历史验证结果。下文的“只挂载当前活动视频页”和频道未接入描述已由后续 [播放器与标签保留](player-workspace.md) 修正；当前行为以该文与根 README 为准。

## 本轮实现

- 移除宽屏侧栏，改为顶部工作区标签与横向频道；Windows 标题栏与标签条合并，支持原有窗口拖动/最大化/最小化/关闭能力。其他平台保留原生窗口装饰。
- 白底、粉色选中条、灰色细边与浅灰卡片信息区；封面 3:2、两行标题、观看/弹幕/时长，宽屏约七列。暗色主题、窄屏、键盘焦点和双倍字体同步适配。
- 固定首页不可关闭；新建浏览、搜索、视频、历史、设置与下载入口支持独立标签。最多 16 个标签，支持 Ctrl+T/W/Tab/Shift+Tab；标签只在进程内保留。
- 每个浏览/搜索标签有独立控制器、查询和滚动状态；关闭释放请求，账号状态变化重建各页面作用域。首页频道内也保留已加载的列表和子导航。
- 只挂载当前活动视频页，切离或关闭释放面板，沿用进程级 PlaybackSession；返回时重新准备并调用已有续播。没有多标签后台播放或第二个播放器。

## 频道能力

| 入口 | 当前行为与验证边界 |
| --- | --- |
| 推荐 | 独立 Web 推荐端点，本轮游客在线返回 20 条；不再复用热门响应 |
| 热门 | 原有真实热门与分页 |
| 分区 | 分类切换及独立 Web 分区投稿端点，本轮游客在线返回 20 条 |
| 排行榜 | 全站/分区排行榜请求与错误重试；本轮在线请求遭遇 `-352` 风控，未验证成功榜单，不回退热门 |
| 动态、视频动态、稍后再看、我的收藏 | 独立入口/子导航、账号按钮和明确的未接入提示；登录也不会伪造列表 |
| 番剧、国创、直播、放映厅 | 独立入口/子导航和明确的未接入提示；不宣称 PGC、直播列表或播放已完成 |
| 下载 | 独立标签提示尚未接入；没有创建下载任务 |

端点、鉴权、签名和分页登记见 [API 端点验证](api-endpoints.md)。新增请求只有只读 GET，不使用账号写操作。

## 验证

Windows 原生测试 `tool/test-windows-media.ps1` 已通过：受控 DASH 分轨、系统安全存储、六次全屏/Esc，以及新增多标签播放生命周期测试。新用例实际挂载工作区和原生 PlaybackPanel，确认切回首页后播放器 idle、返回视频后音视频两轨重新解码、关闭视频标签后再次 idle。该命令未启用公网 UGC 用例；测试器显示的 5 项中有 1 项是未开启的在线分支，实际执行 4 项本地验证。

`tool/check.ps1 -SkipPub` 全量通过：根应用 **64** 项、bili_api **15** 项、bili_player **8** 项、bili_danmaku **4** 项，共 **91** 项。根与各包格式、静态分析均通过。覆盖标签新建/关闭/键盘、满额替换、关闭中间标签后状态保留、账号切换取消、搜索隔离、频道滚动恢复、所选分 P 往返、停止期间同源重开、双主题与双倍字体。Markdown **95** 条本地链接和领域/页面依赖边界检查通过。

Windows x64 Release 构建成功，并直接启动最终可执行文件核对真实推荐封面、七列宽屏网格、窗口标题栏按钮贴右、新建浏览标签及番剧子导航。原生测试在播放竞态修复后重新运行通过。Android arm64 Debug 构建成功；没有连接设备，不宣称 Android 原生播放或交互已实测。最终 Windows 可执行目录是 `build/windows/x64/runner/Release/`，Android 构建为 `build/app/outputs/flutter-apk/app-debug.apk`，均为本地输出，未发布。

快捷键已通过 widget 回归，包括实际番剧时间表按钮获得焦点后 Ctrl+T / Ctrl+Tab。桌面按键自动化复核期间工具检测到用户同时输入，未取得可用结果，因此原生键盘快捷键保持待确认；鼠标新建和频道/子导航切换已实际操作。

整合中修复了三个生命周期问题：删除中间标签导致后续缓存页重新建立、标签达到上限时沿用旧搜索草稿，以及进度写入期间同源快速重开被旧停止流程覆盖。另将所选分 P 写回当前标签 URI，卸载后恢复正确选集。

未进行 Android/macOS 本轮运行、真实账号私有列表验证、重启标签恢复、30 分钟稳定性或性能测量。原有 Flutter Windows 辅助功能崩溃风险继续保留在 [M0 记录](m0-results.md) 中。
