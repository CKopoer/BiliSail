# 页面性能热点与优化方案

日期：2026-10-28。调查基线：`cb067d9`，开始时工作区干净。

## 调查口径

先核对当前页面、共享列表及已有性能记录，再选择仍存在的重复工作。源码调用链证明工作会发生；组件计数证明固定输入下的构建／遍历变化，均不能代替 Profile／Release 帧耗时或实机主观体验。

已核查首页、搜索、历史、评论、下载、消息、用户空间、视频合集和稍后再看侧栏。首页／搜索／历史已使用 Sliver，共享评论已按需创建和局部订阅，收藏夹视频网格已有独立缓存组件；不把历史已修复问题再次计入。本轮不调整播放时钟、原生输出、弹幕预算、图片缓存容量或导航动效。

| 页面 | 当前调用链证据 | 本轮方案 | 必须保留的行为 |
| --- | --- | --- | --- |

## 实施与验证约束

三项分别由 GPT-6.1 Sol、xhigh 子代理实施，文件所有权分开。先用同一组件探针记录原实现的多余工作，再在修复后验证；测试应覆盖用户行为、回调新鲜度和滚动状态，不只验证某个内部类名。

主代理审查合并差异并执行 `tool/check.ps1 -SkipPub`，包含根应用和四包。依赖、锁文件、数据库与 API 协议不变。没有真实账号写入、设备安装或发布。尝试发现可热重载的调试应用，无可用连接时如实记录。

### 实现边界和行为回归

- 下载按任务 ID 索引与稳定结构拆分订阅，搜索标题归一化与分组复用，卡片采用 builder。索引只保留当前快照，无历史列表／Widget 全量缓存；最后一个 UI 订阅释放后自动销毁，进程级下载仓储不受影响。额外验证隐藏任务进度不会重建任何已挂载卡片。
- 空间根仅观察头部、当前分类与会话，保留子页各自观察列表／查询。`ProfileSectionContent` 复用类型判断、动态映射和懒委托，真实宽度／文字缩放改变才调整投稿网格。主题、字体、回调、同长度替换与新分页继续更新。
- 消息导航、未读数、会话、正文与分页尾部独立订阅；原自动已读可见性／会话／正文身份守卫保留。正文回调通过当前 State 转发；发送完成同步已重开会话的草稿。私信图片仍在关闭时驱逐。

新增回归入口：[下载进度隔离](../../test/features/downloads/download_progress_isolation_test.dart)（7 项）、[空间列表](../../test/features/profile/profile_section_performance_test.dart)（11 项）、[消息局部更新](../../test/features/messages/messages_performance_test.dart)（5 项）。下载目录定向 91 项通过、13 项符号链接权限相关用例跳过；空间定向 134 项、消息定向 69 项通过。各修改文件定向分析和格式检查通过。

原始空间基线／复测日志在本地忽略目录 `build/profile-section-baseline.log`、`build/profile-section-optimized.log`、`build/profile-section-targeted.log`。消息原实现用同一测试的 `--dart-define=MESSAGE_REBUILD_BASELINE=true` 记录基线；修复后默认断言为零。
